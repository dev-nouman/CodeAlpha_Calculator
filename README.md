# CodeAlpha-Calculator

## Description
CA-Calculator is a responsive web calculator built with HTML, CSS, and JavaScript. It performs basic operations (+, −, ×, ÷, %) with clear, backspace, real-time display, and keyboard support. Fully responsive with smooth button animations for desktop and mobile use.

## Features
- Basic arithmetic: `+`, `−`, `×`, `÷`, `%`
- Clear (`C`) and backspace (`⌫`) functionality
- Real-time calculation display
- Keyboard support for numbers and operators
- Fully responsive design for desktop and mobile
- Smooth button hover and click animations

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Use
1. Open `index.html` in your browser.
2. Click buttons or use your keyboard to enter numbers and operators.
3. Press `=` or `Enter` to calculate.
4. Use `C` to clear the display or `⌫` to delete the last digit.
